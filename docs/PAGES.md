# Site Pages

All pages are built in **Elementor Pro** on staging, using the shared design
system, the global Theme Builder header/footer, the full-screen mobile menu,
the scroll-reveal animations, and the mobile sticky action bar. Content was
sourced from the old uberrito.com site and adapted.

| Page | Slug | Highlights |
|---|---|---|
| Home | `/` | Hero, LTO, Summer Faves, menu grid, protein, rewards, signup, locations, catering, app, why-Uberrito |
| Menu | `/menu/` | Category grid, "Build Your Own" 3-step (base → protein → flavor), allergen/nutrition band, order CTA |
| Our Story | `/our-story/` | Brand story, chef feature, "Fresh is the Foundation", Quality/Variety/Experience values |
| Rewards | `/rewards/` | Eat·Earn·Eat Free, member perks (free food, birthday, 1pt/$1), 3-step, app band |
| Catering | `/catering/` | Burrito-bar pitch, groups 10–200, "$12/person" anchor, Get a Quote |
| Locations | `/locations/` | Location cards (Champions, Atascocita) with Pickup/Delivery |
| Gift Cards | `/gift-cards/` | "Give the gift that says Mmmm", Buy / Check Balance |
| Food Truck | `/food-truck/` | "You Book. We Cook.", booking CTA |
| Contact | `/contact/` | Elementor contact form (topic select) + hours/locations |
| FAQs | `/faqs/` | Accordion: rewards, delivery, catering, vegan/allergy, app, gift cards |

Navigation (header, full-screen mobile menu, footer) points to these pages.
Footer adds Sitemap + Privacy Policy and collapses to a two-column grid on
mobile.
